# KK Compass 2

加密貨幣多時區結構掃描 ＋ 回測驗證。取代原本的 KK Compass。

## 它做什麼

| 時間（台北） | 動作 |
|---|---|
| 每天 08:10 | 完整報告：抓約 100 個幣、重跑 6 年回測、產生每個幣的策略建議，Telegram 傳摘要與進場計畫 |
| 每 4 小時（00/04/08/12/16/20 點 +3 分） | 掃描最新的 4H 與日線，有「回測支持」的新進場就傳 Telegram |

## 第一次使用（Windows）

1. 安裝 Python 3.12 以上：https://www.python.org/downloads/ ，安裝畫面**勾選 Add python.exe to PATH**。
2. 雙擊 `setup.bat`（安裝套件）。
3. 雙擊 `run_daily.bat`。第一次要下載 6 年數據，約 10～15 分鐘，之後每天約 3 分鐘。跑完會自動開啟報告。
4. 設定 Telegram（見下方），雙擊 `test_telegram.bat` 測試。
5. 雙擊 `install_schedule.bat` 建立自動排程。

## Telegram 設定

1. 在 Telegram 找 **@BotFather**，傳 `/newbot`，照指示取名，會拿到一串 token。
2. 對你的新 bot 隨便傳一句話。
3. 用瀏覽器打開 `https://api.telegram.org/bot<你的token>/getUpdates`，找到 `"chat":{"id":123456789` 這串數字。
4. 用記事本打開 `config.json`，填入：
   ```
   "telegram_bot_token": "你的token",
   "telegram_chat_id": "123456789",
   ```

建議為這個工具開一個新的 bot，不要和其他用途共用。這個工具**不需要任何交易所 API 金鑰**。

## 兩套策略

| | 短線 | 波段 |
|---|---|---|
| 結構確認 | 4H 收盤「不破低再過高」／「不過高再破低」 | 日線收盤，同樣規則 |
| 進場 | 下一根 1H 開盤（或掛單等回踩觸發價） | 隔天開盤（或掛單等回踩） |
| 停損／止盈 | 每天由回測自動挑（只看樣本內 A 級），報告上會寫 | 同左 |
| 最長持有 | 7 天 | 60 天 |
| 建議每筆風險 | 依歷史最大回撤換算（目標回撤 ≤ 20%） | 同左 |

策略卡只在「A／B 級＋該方向在 6 年與樣本外都為正」時才給做多／做空，否則顯示觀望與等待條件。

## 分級（依回測證據）

| 等級 | 條件 | 意義 |
|---|---|---|
| A | BTC 日線分數 ≥ +4 做多／≤ −4 做空，且回檔停損 ≤ 5.5% | 歷史上唯一穩定為正的組合 |
| B | 同上，但停損 > 5.5% | 也為正，但停損寬、部位要縮小 |
| C | BTC 在 −3 ～ +3 | 歷史上約打平 |
| D | 逆著 BTC 明確趨勢 | 歷史上樣本外為負 |

完整數字在報告的「回測驗證」頁，每天自動重算。

## 可調整的設定（config.json）

- `top_n`：掃描幾個幣（預設 100）
- `btc_strong_score`：BTC 分數多少算「趨勢明確」（預設 4）
- `max_risk_pct`／`max_risk_pct_d`：短線／波段 A 級停損上限 %（預設 5.5／15）
- `target_max_dd_pct`：建議倉位要控制的歷史最大回撤 %（預設 20）
- `notify_grades`：哪些等級要通知（預設 `["A","B"]`）
- `max_hold_hours`：回測最長持有時間（預設 168 小時）

改了門檻就會改變回測結果；請只在有理由時調整，並看樣本外數字是否還成立，不要一直調到數字好看為止。

## 檔案

- `run.py` 主程式（`daily`／`scan`／`test-telegram`）
- `kkc/data.py` 抓資料（Binance 公開行情、Hyperliquid 資金費率）
- `kkc/signals.py` 日線方向計分、4H「不破低再過高」、分級、日線篩選規則
- `kkc/backtest.py` 回測撮合、隨機對照組
- `kkc/report.py` 產生報告頁面
- `tests/test_core.py` 無未來函數與撮合測試（`python tests/test_core.py`）

## 限制

- 價格來自 Binance 現貨，不是 Bybit 合約，小幣可能有價差。
- 幣種清單是今天的成交額前段，回測有倖存者偏差。
- 回測從 2020 年起（波段從 2018 年起），樣本外約最近 1.5 年。短線 A 級做多在樣本外為負，所以目前短線只會建議做空方向；這會隨每天重算更新。
- 這是規則式工具，不是投資建議。
